# Código Divino — clone estático

Landing page responsiva reconstruída a partir do site público de referência. Todas as 19 imagens e as fontes usadas pela página estão armazenadas localmente em `assets/`.

## Executar localmente

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.

Os botões de compra apontam para o checkout da Hotmart: `https://pay.hotmart.com/J96665563U?checkoutMode=10`.
